# फ़्रंटएंड

इस डायरेक्टरी में Fruitful के वेब इंटरफ़ेस रखे गए हैं।

## सब-ऐप्स

- `app/` – Next.js साइट, जो मुख्य यूज़र इंटरफ़ेस प्रदान करती है।
- `chat-ui/` – Vite और React से बनाया गया संवादात्मक (conversational) इंटरफ़ेस। आर्किटेक्चर संबंधी विवरण के लिए [chat-ui/ARCHITECTURE.md](chat-ui/ARCHITECTURE.md) देखें।

## एनवायरनमेंट वेरिएबल्स

दोनों सब-ऐप्स बैकएंड सेवाओं से संवाद करने के लिए एनवायरनमेंट वेरिएबल्स पर निर्भर करते हैं।

### Next.js (`app/`)

- `NEXT_PUBLIC_BACKEND_URL` – बैकएंड API अनुरोधों के लिए बेस URL।
- `NEXT_PUBLIC_API_KEY` – Next.js साइट से आने वाले अनुरोधों को अधिकृत करने के लिए उपयोग की जाने वाली API कुंजी।
- `NEXT_PUBLIC_APPSYNC_GRAPHQL_ENDPOINT` – AppSync GraphQL एंडपॉइंट URL।
- `NEXT_PUBLIC_APPSYNC_API_KEY` – AppSync अनुरोधों के लिए API कुंजी।

### Chat UI (`chat-ui/`)

- `VITE_API_BASE_URL` – चैट इंटरफ़ेस द्वारा उपयोग किए जाने वाले API का बेस URL।
- `VITE_API_KEY` – चैट इंटरफ़ेस द्वारा उपयोग की जाने वाली API कुंजी।
