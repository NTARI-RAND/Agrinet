# الواجهة الأمامية

يستضيف هذا المجلد واجهات الويب الخاصة بـ Fruitful.

## التطبيقات الفرعية

- `app/` – موقع Next.js الذي يوفر واجهة المستخدم الرئيسية.
- `chat-ui/` – واجهة محادثة مبنية باستخدام Vite و React. راجع [chat-ui/ARCHITECTURE.md](chat-ui/ARCHITECTURE.md) للاطلاع على التفاصيل المعمارية.

## متغيرات البيئة

يعتمد كلا التطبيقين الفرعيين على متغيرات البيئة للتواصل مع خدمات الواجهة الخلفية.

### Next.js (`app/`)

- `NEXT_PUBLIC_BACKEND_URL` – عنوان URL الأساسي لطلبات واجهة برمجة التطبيقات (API) في الواجهة الخلفية.
- `NEXT_PUBLIC_API_KEY` – مفتاح API المستخدم للتصريح بالطلبات الصادرة من موقع Next.js.
- `NEXT_PUBLIC_APPSYNC_GRAPHQL_ENDPOINT` – عنوان URL لنقطة نهاية GraphQL الخاصة بـ AppSync.
- `NEXT_PUBLIC_APPSYNC_API_KEY` – مفتاح API لطلبات AppSync.

### واجهة المحادثة (`chat-ui/`)

- `VITE_API_BASE_URL` – عنوان URL الأساسي لواجهة API التي تستخدمها واجهة المحادثة.
- `VITE_API_KEY` – مفتاح API الذي تستخدمه واجهة المحادثة.
