# Agrinet — तकनीकी दस्तावेज़ीकरण

ब्राज़ील के लिए विकेन्द्रीकृत कृषि मार्केटप्लेस। यह किसी सौदे के पूरे चक्र को कवर करता है: लिस्टिंग का प्रकाशन, एस्क्रो के साथ भुगतान, विक्रेता को राशि जारी करना, रियल-टाइम चैट, एंटी-फ्रॉड और नोड्स के बीच फ़ेडरेशन।

**फ्रंटएंड:** Next.js 14 + Tailwind + Shadcn/ui + Framer Motion  
**बैकएंड:** Node.js + Express + MariaDB + Redis  
**इन्फ्रा:** Docker Compose + GitHub Actions CI/CD + Cloudflare R2

---

## मुख्य व्यावसायिक पाइपलाइन

```
Listing criado pelo seller
        |
        v
Buyer inicia transacao
        |
        v
Pagamento via Stripe (PaymentIntent)
        |
        v
Webhook confirma pagamento --> transaction: paid
        |
        v
Seller libera escrow
        |
        v
Wallet do seller creditada --> transaction: completed
```

## स्टैक

| परत | तकनीक |
|---|---|
| बैकएंड HTTP | Node.js + Express |
| डेटाबेस | MariaDB |
| भुगतान | Stripe PaymentIntent API |
| प्रमाणीकरण | JWT + bcryptjs |
| रियल-टाइम | Socket.IO |
| कैश और क्यू | Redis + BullMQ |
| ऑब्ज़र्वेबिलिटी | Prometheus + Grafana |
| फ़ाइल अपलोड | Multer |

## आगामी चरण

**चरण 4 — PIX**
ब्राज़ीलियाई बाज़ार में वास्तविक उपयोग के लिए Stripe के माध्यम से PIX एकीकरण। PIX इवेंट्स के लिए एक समर्पित टेबल और सुरक्षित वेबहुक की आवश्यकता है।

**चरण 5 — संपूर्ण कृषि लिस्टिंग**
श्रेणी-विशिष्ट एट्रिब्यूट, प्रमाणन, उत्पत्ति की ट्रेसेबिलिटी और विस्तृत कृषि कैटलॉग।

**चरण 6 — फ्रंटएंड** ✅ पूर्ण
मार्केटप्लेस, चैट, प्रोफ़ाइल, एडमिन और संपूर्ण एग्रो डिज़ाइन सिस्टम के साथ Next.js 14।

**चरण 7 — प्रोडक्शन इन्फ्रास्ट्रक्चर** ✅ पूर्ण
Docker Compose, GitHub Actions के साथ CI/CD, Docker Hub पर इमेज, स्वचालित बैकअप, अपलोड के लिए Cloudflare R2।

**चरण 8 — डोमेन और डिप्लॉय**
डोमेन को सर्वर की ओर पॉइंट करना, HTTPS कॉन्फ़िगर करना (nginx/Caddy), CI में `NEXT_PUBLIC_API_URL` अपडेट करना।

**चरण 9 — PIX**
ब्राज़ीलियाई बाज़ार में वास्तविक उपयोग के लिए Stripe के माध्यम से PIX एकीकरण।
