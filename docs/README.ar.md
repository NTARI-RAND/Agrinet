# Agrinet — التوثيق التقني

سوق زراعي لامركزي مخصص للبرازيل. يغطي الدورة الكاملة لأي تعامل: نشر الإعلان، والدفع مع حفظ المبلغ في الضمان (escrow)، والإفراج عن المبلغ للبائع، والمحادثة الفورية، ومكافحة الاحتيال، والاتحاد بين العُقد.

**الواجهة الأمامية (Frontend):** Next.js 14 + Tailwind + Shadcn/ui + Framer Motion  
**الواجهة الخلفية (Backend):** Node.js + Express + MariaDB + Redis  
**البنية التحتية (Infra):** Docker Compose + GitHub Actions CI/CD + Cloudflare R2

---

## المسار التجاري الرئيسي

```
إنشاء الإعلان (listing) بواسطة البائع (seller)
        |
        v
بدء المعاملة بواسطة المشتري (buyer)
        |
        v
الدفع عبر Stripe (PaymentIntent)
        |
        v
الـ webhook يؤكد الدفع --> transaction: paid
        |
        v
البائع يُفرج عن مبلغ الضمان (escrow)
        |
        v
إيداع المبلغ في محفظة البائع --> transaction: completed
```

## حزمة التقنيات

| الطبقة | التقنية |
|---|---|
| الواجهة الخلفية HTTP | Node.js + Express |
| قاعدة البيانات | MariaDB |
| المدفوعات | Stripe PaymentIntent API |
| المصادقة | JWT + bcryptjs |
| الزمن الفعلي | Socket.IO |
| التخزين المؤقت وقوائم المهام | Redis + BullMQ |
| قابلية المراقبة | Prometheus + Grafana |
| رفع الملفات | Multer |

## المراحل القادمة

**المرحلة 4 — PIX**
التكامل مع PIX عبر Stripe للاستخدام الفعلي في السوق البرازيلية. يتطلب جدولاً مخصصاً وwebhook آمناً لأحداث PIX.

**المرحلة 5 — إعلانات زراعية كاملة**
سمات خاصة بكل فئة، وشهادات، وتتبع مصدر المنتج، وكتالوج زراعي مفصّل.

**المرحلة 6 — الواجهة الأمامية** ✅ مكتملة
Next.js 14 مع السوق والمحادثة والملف الشخصي ولوحة الإدارة ونظام تصميم زراعي كامل.

**المرحلة 7 — البنية التحتية للإنتاج** ✅ مكتملة
Docker Compose، وCI/CD عبر GitHub Actions، والصور على Docker Hub، والنسخ الاحتياطية التلقائية، وCloudflare R2 لرفع الملفات.

**المرحلة 8 — النطاق والنشر**
توجيه النطاق إلى الخادم، وتهيئة HTTPS (nginx/Caddy)، وتحديث `NEXT_PUBLIC_API_URL` في CI.

**المرحلة 9 — PIX**
التكامل مع PIX عبر Stripe للاستخدام الفعلي في السوق البرازيلية.
